# Sample Audio Files

Use this folder for small demo audio files.

Recommended structure:

```text
samples/
├── real/
│   ├── real_001.wav
│   └── real_002.wav
└── fake/
    ├── fake_001.wav
    └── fake_002.wav
```

Do not upload a full dataset to GitHub if it is large. Keep only short examples for demonstration.
